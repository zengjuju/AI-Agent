Forge —— 自研编程智能体

Git 仓库：https://github.com/zengjuju/AI-Agent

一、项目简介
Forge 是运行在本地终端的编程智能体，通过与大语言模型交互，能自主读写文件、执行命令、语义检索代码，完成编程任务。核心逻辑全部自行编写，不使用任何智能体框架或 SDK（如 LangChain、LlamaIndex、AutoGen、CrewAI 等），不依赖服务端托管的代码执行或文件工具。

二、技术栈
TypeScript + Node.js 22；OpenAI 兼容原生函数调用接口；零运行时第三方依赖。

三、如何运行
1. 安装依赖：npm install
2. 配置凭据（二选一）：
   方式 A 环境变量：设置 API 密钥、接口地址、模型名称三个环境变量。
   方式 B 配置文件：首次启动自动生成配置文件（已被 .gitignore 忽略），将 API 密钥、接口地址、模型名称填入即可，无需每次设置环境变量。语义检索功能需额外配置向量嵌入模型的密钥和地址（支持与对话模型不同厂商）。
3. 编译：npm run build
4. 离线演示（无需密钥）：node dist/src/cli/index.js --demo
5. 终端交互：node dist/src/cli/index.js
6. 浏览器交互：node dist/src/cli/index.js --serve --port 8790

四、特色功能
1. 智能体循环：模型自主多轮调用工具，工具结果自动回填给模型继续推理；当模型不再请求调用工具时即视为任务完成并终止循环。模型调用失败时指数退避重试，设有最大轮次防止无限循环。
2. 11 个内置工具：目录列举、文件读取（含分页）、文件写入、增量编辑、命令执行、文件名搜索、内容搜索、语义检索、网页抓取、新闻查询、偏好管理。其中写入文件与执行命令需用户审批确认。
3. 四层上下文压缩：第一层按 token 而非消息条数估算上下文用量；第二层截断过长的工具输出并清理终端转义码；第三层以滑动窗口保留最近对话、永不切割系统提示与最近两轮完整交互；第四层在仍超阈值时调用模型生成结构化交接摘要。四层逐级触发，低成本优先。
4. 会话持久化：采用追加式事件日志存储，每条消息同步落盘，支持会话恢复、分叉与删除，进程重启不丢失历史。
5. 长期记忆：用户偏好持久化存储，每次构建系统提示时自动注入，模型可通过偏好管理工具自主保存与遗忘，跨会话生效。
6. 多智能体协作：采用规划者-执行者范式与角色专业化混合架构，包含规划、工程师、研究员、审查员、架构师五个角色，各角色拥有独立的提示词与工具白名单。子任务按依赖关系拓扑排序并行执行，审查员评分不达标时自动触发修正轮。
7. RAG 语义检索：对代码文件按语法树边界分块，将块文本向量化后存入本地向量库，同时构建关键词倒排索引。检索时并行执行语义相似度搜索与关键词搜索，通过倒数排名融合算法合并两路结果，可选模型重排序。智能体自主决定何时检索，返回结果附带文件路径与行号引用。
8. 三种运行形态：离线演示模式（无需密钥）、终端交互模式、浏览器 Web 界面（含会话管理、偏好管理、多智能体可视化、过程详情默认折叠）。

五、凭据安全
API 密钥等凭据一律通过环境变量或未入库的配置文件提供，不出现在仓库、README.txt 或视频中。配置目录已被 .gitignore 忽略。
